# How to Format

<details>

<summary>General Text Formatting</summary>

The following formatting can be achieved by using specific symbols around the text you would like it to affect.

_Italics_ - \*italics\* or \_italics\_

_<mark style="color:yellow;">Underline italics</mark>_ - \_\_\*underline italics\*\_\_

**Bold -** \*\*bold\*\*

<mark style="color:yellow;">**Underline bold**</mark> - \_\_\*\*underline bold\*\*\_\_

_**Bold Italics**_ - \*\*\*bold italics\*\*\*

_<mark style="color:yellow;">**underline bold italics**</mark>_ - \_\_\*\*\*underline bold italics\*\*\*\_\_

<mark style="color:yellow;">Underline</mark> - \_\_underline\_\_

~~Strikethrough~~ - \~\~Strikethrough\~\~

Don't want to use markdown? You can slap a backslash before your statement or put your message in a code block, escaping the markdown formatting. You'll see those asterisks as you'd like!

</details>
